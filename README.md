# ستوديو ليدي للتصوير النسائي — Lady Studio (Demo)

نسخة عرض (واجهة أمامية) لموقع **ستوديو ليدي للتصوير النسائي** في حي القدس، الرياض. Vue 3 + Vite، عربي/إنجليزي.

## التشغيل
```bash
npm install
npm run dev
```
الرفع على Vercel: GitHub ثم Import (Build: `npm run build`، Output: `dist`).

## الأصول (`public/img/`)
من صور الاستوديو على خرائط Google: الواجهة الليلية (اللافتة)، الاستقبال، صالة الانتظار، ركن التصوير، ركن الألبومات، جلسة الانتظار، ونماذج أعمال (تصوير منتج عطر، ولقطة مناسبة).
استبعدت صوراً لاستوديوهات أخرى ظهرت على صفحتهم (لمار، لون كادي، تلادة…).
موقعهم الحالي photo-lady.com دومينه غير موجود. لم أجد حساب سوشيال ميديا ظاهراً.

## المحتوى
- قسم "اشتراطات صورة الأحوال" منقول من الورقة المعلّقة في الاستوديو (من صورهم).
- الخدمات من تصنيفاتهم على Google: صور جوازات، معمل صور، ترميم الصور القديمة، إطارات، تصوير زفاف.
- "نوف" هي المصورة التي يتكرر اسمها في المراجعات.
- "طاقم نسائي بالكامل" استنتاج من كونه استوديو نسائياً ومن المراجعات — تأكد منه.

## قبل الإطلاق الرسمي
احذف `noindex` من `index.html` وشريط "نسخة عرض" من `src/App.vue`.
